# Data Dictionary

`sample_worker_task_records.csv`: worker/task type, shift duration, repetition, manual handling, posture, force, vibration, pacing, discomfort, prior injury and missed-break indices.

`sample_workstation_assessments.csv`: workstation-fit gap indicators.

`sample_discomfort_reports.csv`: synthetic reported discomfort records by body region, severity and status.

`sample_shift_environment_context.csv`: synthetic monthly workload/environment context by zone.
