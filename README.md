# Workplace Ergonomic Injury Risk Analyzer — ErgoGuard Local

Privacy-conscious, local-first Streamlit platform for screening workplace ergonomic conditions using authorized worker-task, workstation, discomfort and shift/environment records.

## Highlights
- Explainable 0–100 ergonomic-risk screening score
- Low / Moderate / High / Critical bands
- Repetition, posture, manual handling, force and vibration analysis
- Shift-duration, task-pacing and missed-break context
- Workstation-fit gap analytics
- Reported discomfort trends and severity
- Department and zone comparisons
- Ergonomic priority-review queue
- Adjustable Scenario Lab
- CSV upload and export
- No external APIs
- Synthetic demonstration data
